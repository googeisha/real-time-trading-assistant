# Robinhood Market Researcher - Dependencies

## Required Python Packages

The following Python packages are required to run the Robinhood Market Researcher:

- pandas
- numpy
- requests
- matplotlib
- tkinter (usually included with Python)

## Installation

Install the required packages using pip:

```bash
pip install pandas numpy requests matplotlib
```

Note: tkinter is typically included with standard Python installations.

## Verification

All dependencies have been tested and confirmed to be working with the current implementation.
